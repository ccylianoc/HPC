# High Performance Computing

In deze README kan je alle informatie vinden over de Graphics Engine die we moesten maken voor school.

In de /Engine dir zijn een aantal bestanden te vinden

matrix.* ,vector.* , shaders.* ,engine.* ,draw.* ,shapes.h

Dit is onze library's alles wordt in de c++ header gedefined en in cpp geinitialiseerd.

## Hoe gebruiken we deze library's

Je maakt een .cpp file aan waar je alle library's include

```cpp
#include "file.name"
```

### Eigen note Git

```cmd
cmd /c .\git-push.bat
```
